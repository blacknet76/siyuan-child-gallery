## External SiYuan SDK and host

The `siyuan@1.2.9` SDK from `siyuan-note/petal` provides development types and host
integration. It is external to the production bundle; SiYuan supplies the runtime.
No SDK implementation or type files are distributed in the plugin package. The
inspected SDK package declares no license; this notice does not assign it one.

The `iconSettings` icon is referenced by its host identifier; its SVG geometry
is not copied into the plugin. Other dependencies are development,
test or build tools recorded in `pnpm-lock.yaml`, not complete libraries shipped
with the plugin.
